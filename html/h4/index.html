The <h4> Element

As defined in the HTML Living Standard, the <h4> element represents a fourth-level heading.

Visual Example:

This is a Rank 4 Heading

<h4>Detailed Sub-section Heading</h4> View HTML Living Standard: Headings

Usage in Complex Documents

H4 headings are typically used in very long, technical documents or complex guides to maintain a clear hierarchy.

  • Maintain Sequence: Ensure an H4 is preceded by an H3.
  • Clarity: If you find yourself needing H4s, H5s, and H6s frequently, consider if the content should be split into multiple pages.

WCAG Requirement: Info and Relationships

Success Criterion 1.3.1 (Level A): Information, structure, and relationships conveyed through presentation can be programmatically determined.

Consistent heading levels provide a reliable map for users navigating via screen readers.
