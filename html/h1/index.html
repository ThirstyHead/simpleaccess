The <h1> Element

As defined in the HTML Living Standard, the <h1> element represents the highest-level heading in a document. It is used to identify the main topic of the page.

Visual Example:

This is a Rank 1 Heading

<h1>The Main Page Title</h1> View HTML Living Standard: Headings

Accessibility & SEO

The <h1> is critical for both accessibility and search engine optimization.

  • One H1 per Page: While HTML5 technically allows multiple H1s (within sectioning elements), the best practice for accessibility is to have a single, unique H1 that describes the page's primary purpose.
  • Screen Reader Navigation: Users of assistive technology often use the H1 to confirm they have landed on the correct page.

WCAG Requirement: Info and Relationships

Success Criterion 1.3.1 (Level A): Information, structure, and relationships conveyed through presentation can be programmatically determined.

Correct use of the H1 ensures that the primary purpose of the page is programmatically identifiable.
