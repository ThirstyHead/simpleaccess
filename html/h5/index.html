The <h5> Element

As defined in the HTML Living Standard, the <h5> element represents a fifth-level heading.

Visual Example:
This is a Rank 5 Heading
<h5>Minor Sub-section Heading</h5> View HTML Living Standard: Headings

Deep Nesting

The H5 is rarely used in standard web pages but is available for highly structured data or documentation.

  • Avoid Skipping: Never jump from an H2 to an H5.
  • User Experience: Be mindful that too many heading levels can make a page feel fragmented.

WCAG Requirement: Info and Relationships

Success Criterion 1.3.1 (Level A): Information, structure, and relationships conveyed through presentation can be programmatically determined.

Maintaining the heading sequence is essential for the programmatic determination of document structure.
