The <menu> Element

As defined in the HTML Living Standard, the <menu> element is a semantic alternative to <ul> for lists of interactive commands.

Visual Example:
    •
    <menu>\n <li><button>Save</button></li>\n <li><button>Edit</button></li>\n</menu> View HTML Living Standard: The menu element

    Menu vs. Nav

    It is important to distinguish between <menu> and <nav>.

    • <nav>: Used for primary site navigation (links to other pages).
    • <menu>: Used for a list of commands or actions (buttons that trigger functions on the current page).

    A11y Tip: Command Lists

    Using <menu> provides a semantic hint that the list contains actions. When combined with proper ARIA roles (if needed for complex apps), it helps users understand the purpose of the interactive group.
