The <search> Element

As defined in the HTML Living Standard, the <search> element represents a section of a page that contains a search functionality.

Visual Example:
<search>\n <form action="/search" method="GET">\n <input type="search" name="q">\n <button>Search</button>\n </form>\n</search> View HTML Living Standard: The search element

Accessibility & Landmarks

The <search> element is a landmark. This allows users to jump directly to the search feature of a website.

  • Semantic Clarity: Using <search> is more descriptive than using a generic <div> or <section>.
  • Input Type: Always use type="search" for the input field to provide a better user experience on mobile devices (e.g., adding a "clear" button).

WCAG Requirement: Info and Relationships

Success Criterion 1.3.1 (Level A): Information, structure, and relationships conveyed through presentation can be programmatically determined.

The <search> landmark ensures that the search functionality is programmatically identifiable.
