The <h3> Element

As defined in the HTML Living Standard, the <h3> element represents a third-level heading, used for sub-sections within an H2 section.

Visual Example:

This is a Rank 3 Heading

<h3>Sub-section Heading</h3> View HTML Living Standard: Headings

Deep Hierarchy

The <h3> allows for detailed organization of content.

  • Avoid Over-nesting: While H3 through H6 are available, extremely deep nesting can become confusing for users.
  • Visual vs. Structural: Never use an H3 just because you want the text to be smaller; use CSS for styling and the tag for structure.

WCAG Requirement: Info and Relationships

Success Criterion 1.3.1 (Level A): Information, structure, and relationships conveyed through presentation can be programmatically determined.

Correct heading levels allow users to jump to specific sub-topics efficiently using assistive technology.
